💬 Talk to Little Brain

This first version has real saved memory and a small neural network that learns a simple pattern task. It is not yet a general-purpose language model, so its conversation is intentionally simple.

📚 Teach it a fact

Give it something useful to remember. Example: “My favorite game is Minecraft.”

⚡ Train its neural network

Teach it examples of a pattern. The network learns to classify short messages into one of two labels. Start with the sample set, then add your own examples.

Network ready for examples.

🕸️ Neural network

The dots are neurons; the lines are learned connections. Brighter/thicker lines have larger weights. This tiny model uses word features and trains with gradient descent.
